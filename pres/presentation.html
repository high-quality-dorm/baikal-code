Стриминг

Ответ идёт потоком: статус → SQL → токены → done. Первый токен — сразу, без ожидания полного ответа

Безопасность

Три независимых уровня защиты

1

Роли PostgreSQL — принцип наименьших привилегий

Рабочая роль app_ro — только чтение; служебная app_service — только для аудита и аутентификации

2

Row-Level Security — deny-by-default

Доступ задаётся из student_id / staff_id: студент видит свои оценки, преподаватель — свои группы, администрация — всё

3

Публичные вью v_* — статистика без PII

Численность студентов доступна всем, включая гостя, — но персональные данные не раскрываются

Только SELECT Whitelist таблиц Защита от SQL-инъекций (sqlglot) Авто-LIMIT 200 statement_timeout 10 с
