Реализация

Шлюз и мозг — два слоя

Мозг · агент
  • LLM-цикл: думает, действует, исправляет
  • Тул execute_query — один инструмент
  • Промпт под роль и PII-скоуп
  • Настраивается без кода: .env, шаги, лимиты
Шлюз · db
  • Только read-only SELECT
  • Whitelist · авто-LIMIT 200 · statement_timeout
  • RLS-контекст под роль пользователя
  • Каждый запрос — в аудит-логе

Агент предлагает — шлюз решает. В базу напрямую приложение не ходит.

Безопасность

Права — в самой базе, а не в чате

RLS deny-by-default

Строки открыты только по правилам — что не положено, база не отдаст

Роль из данных

Выводится из student_id / staff_id, не хранится в коде

PII студентов — только агрегаты

Численность и статистика — публичные вью, персональные данные — нет

Аудит

Каждый запрос фиксируется: кто, что, когда

Агент не может спросить то, что не положено, — база просто не отдаст.
